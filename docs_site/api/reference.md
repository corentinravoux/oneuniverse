# `oneuniverse.reference`

The reference physics plugin: a toy engine to validate the simulation store and
the twin contracts, not a science code. The package `__init__` exports nothing
and registers nothing, so the API is documented module by module. Importing
`oneuniverse.reference.engines` registers the four engines with `oneuniverse.twin`;
importing `oneuniverse.reference.native` registers the `linear` and `packed_npy`
converters with `oneuniverse.simulation`.
